# OVF UI

OVF UI - графический интерфейс для VMware OVF Tool. Позволяет загружать и скачивать OVA, OVF и ISO в Cloud Director без работы с командной строкой.

Приложение рассчитано прежде всего на **MWS Cloud Director — облако на базе VMware**. Сейчас доступна версия для Windows x64. OVF Tool нужно установить отдельно.

[Скачать для Windows](https://github.com/RareMxxx/OVF-UI/releases/latest)

## Возможности

- Подключение к нескольким ЦОДам и тенантам по логину и паролю или API-токену.
- Просмотр ВМ, vApp, каталогов, шаблонов и ISO.
- Загрузка образов в каталог и скачивание на компьютер.
- Экспорт vApp напрямую или через создание шаблона в каталоге.
- Проверка образа, свободного места и совпадения имён перед загрузкой.
- Очередь и одновременные передачи, ограничение скорости, история и журнал ошибок.

Интерфейс на русском. Есть светлая и тёмная темы.

## Как начать

1. Скачайте архив из [Releases](https://github.com/RareMxxx/OVF-UI/releases) и распакуйте его целиком.
2. Запустите `ovf-ui.exe` и выберите папку с установленным `ovftool.exe`.
3. Добавьте адрес Cloud Director, имя организации и данные для входа.
4. Выберите объект и нажмите «Скачать». Для загрузки своего образа нажмите «Загрузить в каталог».

Установка приложения и права администратора для обычного запуска не нужны. Все файлы из архива должны оставаться рядом с `ovf-ui.exe`.

## Особенности работы

Образы передаются через OVF Tool. Приложение получает список объектов и состояние задач через API Cloud Director. Передача считается завершённой после обработки образа в облаке.

OVF Tool экспортирует vApp целиком. Если внутри несколько ВМ, скачать одну из них отдельно нельзя: нужно выбрать весь vApp или заранее перенести нужную ВМ в отдельный vApp. Выключение ВМ и извлечение подключённого ISO требуют подтверждения.

При экспорте через шаблон он создаётся в выбранном каталоге и остаётся там после скачивания. Для него потребуется дополнительное место. Существующие образы не перезаписываются.

Для длительных операций можно использовать API refresh token: приложение обновляет сессию во время передачи. Обычный Bearer token без refresh token автоматически продлить нельзя. После ошибки повторная передача начинается с начала.

Пароли и токены хранятся локально в Windows Credential Manager. Подключения можно перенести на другой компьютер через зашифрованный экспорт.

Обновления проверяются по публичным релизам этого репозитория. Вход в GitHub не нужен. Новая версия скачивается и устанавливается вручную.

## Сборка из исходников

Проект написан на Rust, интерфейс — egui. Для сборки нужны актуальный stable Rust, PowerShell 7 и Visual Studio C++ Build Tools.

```powershell
pwsh -File ./scripts/build-release.ps1
```

Скрипт заменяет локальные пути исходников в EXE нейтральными и проверяет результат.

Проверки проекта:

```powershell
cargo fmt --all -- --check
cargo test --locked --features test-fixtures
cargo clippy --locked --all-targets --features test-fixtures -- -D warnings
```
